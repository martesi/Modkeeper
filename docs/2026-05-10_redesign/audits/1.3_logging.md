# 1.3 Audit Logging

This audit traces the flow of logs from the backend to the frontend and reviews error handling practices.

## Log Flow (Backend → Frontend)

1. **Initialization:**
   - Backend initializes `tauri-plugin-log` in `lib.rs` with `LevelFilter::Info`.
   - `tracing` macros (`info!`, `error!`, etc.) are used throughout the backend.
2. **Transport:**
   - `tauri-plugin-log` captures `tracing`/`log` output and emits it via Tauri events to the frontend.
3. **Frontend Capture:**
   - The frontend console displays logs from the backend via the plugin's frontend side.
   - **Gap:** There is no persistent log file storage configuration visible in the current `tauri-plugin-log` setup (default may be console-only).

## Error Handling Review

### Backend
- **Practice:** Consistent use of `Result<T, SError>` in commands and services.
- **Gap:** Some `spawn_blocking` calls might swallow errors if not properly awaited and mapped (though `commands/global.rs` seems to handle them).
- **Gap:** Sparse logging in core logic. Errors are returned but not always logged with context before being sent to the frontend.

### Frontend
- **Fatal Errors:**
    - **Gap:** `__root.tsx` does NOT have an `errorComponent`. React crashes or render errors will result in a blank screen.
    - **Gap:** `router.ts` lacks a global `notFoundComponent` and `defaultErrorComponent`.
- **IPC Errors:**
    - **Gap:** Silent failures or unhandled rejections. `LibraryInit` calls `commands.init()` without a `.catch()` or error surfacing.
    - **Practice:** Errors from the backend are likely passed through as rejected promises, but they are not caught and toasted consistently.

## Documented Gaps

| Gap ID | Description | Severity |
|--------|-------------|----------|
| L-001 | No global Error Boundary in React root. | High |
| L-002 | IPC calls lack consistent error handling (silent rejections). | High |
| L-003 | No persistent log file configuration (logs lost on restart). | Medium |
| L-004 | Sparse structured logging in `core/` modules. | Medium |

## Recommendation
- Implement a global `ErrorComponent` in `__root.tsx`.
- Wrap IPC calls in a utility that automatically surfaces errors via `sonner` toasts.
- Configure `tauri-plugin-log` to write to a log file for debugging user issues.
