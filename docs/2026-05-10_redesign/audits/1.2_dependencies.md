# 1.2 Audit Dependencies

This audit reviews the dependencies in `src-tauri/Cargo.toml` and `package.json` for necessity, maintenance, and duplication.

## Backend (Cargo.toml)

| Crate | Status | Recommendation |
|-------|--------|----------------|
| `help` | **Unused** | **Remove**. No usage found in codebase. |
| `confy` | Active | Keep for now, but could be replaced by a simpler `toml` read/write in Phase 2 to reduce dependencies. |
| `toml` | Active | Keep. Essential for manifest management. |
| `camino` | Active | Keep. Excellent for type-safe UTF-8 paths. |
| `dunce` | Active | **Critical**. Essential for Windows path handling (canonicalization). |
| `parking_lot` | Active | Keep. Better performance/API than std Mutex. |
| `derive_more` | Active | Keep. Reduces boilerplate. |
| `tracing` | Active | Keep. Standard for logging. |
| `tauri-plugin-log` | Active | Keep. Bridges backend logs to frontend. |

### Redundancy Check
- `toml` and `confy`: `confy` uses `toml` internally. We could drop `confy` and use `toml` directly for the global config to have more control and one less dependency.
- `serde_json` and `toml`: Both are used. `serde_json` is likely for manifest reading (if JSON) or Tauri IPC. `toml` is for our own manifests.

## Frontend (package.json)

| Package | Status | Recommendation |
|---------|--------|----------------|
| `radix-ui` | **Redundant** | **Remove**. The project already uses individual `@radix-ui/*` packages. `radix-ui` is a legacy meta-package. |
| `ahooks` | Active | Review usage. Many simple hooks can be implemented natively or are already provided by React. |
| `jotai` | Active | Keep. Solid state management. |
| `remeda` | Active | **Highly Recommended**. Great for the FP-first goal of the redesign. |
| `clsx` & `tailwind-merge` | Active | Keep. Standard for Tailwind component development. |
| `@faker-js/faker` | Active | Keep (dev-only). |

### Redundancy Check
- `@radix-ui/*` vs `radix-ui`: Confirmed redundant.
- `lucide-react`: Ensure only used icons are bundled (Vite handles this usually).

## Flagged for Removal
1. `help` (Cargo.toml)
2. `radix-ui` (package.json)
