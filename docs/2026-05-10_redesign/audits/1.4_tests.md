# 1.4 Audit Tests

This audit maps the existing tests in the codebase and evaluates their utility.

## Backend Integration Tests (`src-tauri/tests/`)

| Test File | Description | Utility | Recommendation |
|-----------|-------------|---------|----------------|
| `library.rs` | Comprehensive test (1000+ lines) covering library creation, mod addition, collision detection, syncing, and persistence. | **Very High** | Keep and refactor to match the new paradigm in Phase 2. This is the main safeguard for core logic. |
| `linker.rs` | Tests low-level symlink creation and unlinking. | **High** | Keep. Essential for cross-platform reliability. |
| `mod_fs.rs` | Tests mod identification logic (ID resolution, type inference). | **High** | Keep. Essential for correct mod categorization. |

## Backend Unit Tests (Inline)

- **Findings:** Very few inline `#[cfg(test)]` blocks. Most logic is tested via integration tests.
- **Recommendation:** Increase unit test coverage for pure FP functions as they are extracted in Phase 2.

## Frontend Tests

- **Findings:** **NONE**. No `.test.ts` or `.spec.ts` files found in `src/`.
- **Recommendation:** Introduce `vitest` and add basic unit tests for utility functions (`remeda` pipelines, etc.) and component rendering tests.

## Test Utilities

| File Path | Description | Recommendation |
|-----------|-------------|----------------|
| `src-tauri/src/commands/test.rs` | Tauri commands to create simulation environments for the frontend. | Keep. Useful for manual testing and potential E2E tests. |
| `src-tauri/tests/common/mod.rs` | Shared setup logic for integration tests. | Keep and expand as needed. |

## Summary of Findings

1. **Integration-Heavy:** The backend is well-tested at the integration level, particularly for the complex sync/deploy pipeline.
2. **Frontend Gap:** The frontend has zero automated tests. This is a significant risk for the UI redesign.
3. **Refactor Need:** As the backend moves towards an FP-first paradigm, existing integration tests must be updated to ensure they still cover the refactored logic.
